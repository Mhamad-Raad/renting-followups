# Glossary

The key words of the app in Sorani, English and Arabic. Every translation uses these exact terms so the wording stays consistent. **A native speaker should review the Sorani and Arabic columns**; change a word here first, then in the translation files (`src/renderer/i18n/`).

| English                 | Sorani (کوردی)     | Arabic (العربية) | Meaning in the app                                                                   |
| ----------------------- | ------------------ | ---------------- | ------------------------------------------------------------------------------------ |
| Rent Tracker (app name) | بەدواداچوونی کرێ   | متابعة الإيجارات | The name shown in the title bar and sidebar.                                         |
| Home                    | سەرەکی             | الرئيسية         | The start screen with the summary.                                                   |
| Area                    | شوێن               | عقار             | One rented place: a house, building, tourist area, company or land.                  |
| Areas                   | شوێنەکان           | العقارات         | The list of all areas.                                                               |
| Category                | پۆل                | فئة              | A named group of areas, for example "Houses".                                        |
| Renter                  | کرێچی              | المستأجر         | The person who pays rent for an area.                                                |
| Rent                    | کرێ                | الإيجار          | The monthly amount an area should pay.                                               |
| Payment                 | پارەدان            | دفعة             | Money received from a renter.                                                        |
| Record payment          | تۆمارکردنی پارەدان | تسجيل دفعة       | The main button for entering money received.                                         |
| Receipt                 | پسوولە             | وصل              | The numbered paper given for a payment.                                              |
| Past record             | تۆماری پێشوو       | سجل سابق         | A payment entered afterwards for earlier months; it has no receipt number.           |
| Cancelled (receipt)     | هەڵوەشێنراوە       | ملغى             | A receipt that no longer counts; it stays listed, crossed out, and keeps its number. |
| Received                | وەرگیراو           | المستلم          | Money paid for the rent months of the period.                                        |
| Still owed              | ماوە               | المتبقي          | Rent that should have been paid but is not yet.                                      |
| Paid                    | دراوە              | مدفوع            | A month that is fully paid (green).                                                  |
| Due                     | کاتی دانیەتی       | مستحق            | This month, not fully paid yet (orange).                                             |
| Partly paid             | بەشێکی دراوە       | مدفوع جزئياً     | Some but not all of a month's rent (orange).                                         |
| Late                    | دواکەوتوو          | متأخر            | A past month not fully paid (red).                                                   |
| Upcoming                | داهاتوو            | قادم             | A future month with nothing paid yet (grey).                                         |
| Vacant                  | بەتاڵ              | شاغر             | An area with no rent for now; never late.                                            |
| Not started             | دەستی پێنەکردووە   | لم يبدأ          | A month before the area's rent started; nothing is expected (hatched).               |
| Nothing due             | هیچ داواکراو نییە  | لا شيء مستحق     | A year with no rent expected up to now, for example rent starting later.             |
| Report                  | ڕاپۆرت             | تقرير            | A printable table of areas and totals.                                               |
| Notifications           | ئاگادارکردنەوەکان  | التنبيهات        | Reminders about late rent and backups.                                               |
| Settings                | ڕێکخستنەکان        | الإعدادات        | Language, appearance, printing, backup, security.                                    |
| Backup                  | پاشەکەوتی یەدەگ    | نسخة احتياطية    | A safety copy of all data.                                                           |
| Password                | وشەی نهێنی         | كلمة المرور      | Opens the app on every start.                                                        |
| Recovery phrase         | ڕستەی گەڕانەوە     | عبارة الاسترداد  | A sentence the owner writes down; sets a new password if the password is forgotten.  |
| Month                   | مانگ               | شهر              | Always shown as a number 1–12.                                                       |
| Year                    | ساڵ                | سنة              |                                                                                      |
| IQD                     | دینار              | دينار            | Iraqi dinar, whole numbers only.                                                     |
| USD                     | دۆلار              | دولار            | US dollar, with cents.                                                               |
